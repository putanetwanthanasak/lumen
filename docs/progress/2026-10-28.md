### Done: PR 2 `feat/kidnee-endpoints`
- **`GET /debts/months[?count=N]`** (`app/debts/months.py`):
  - Rows run from this month to the last month an owed installment is due, or exactly N months with `count`. They stop at 600, with `months_truncated`.
  - Each row has `total`, `budget`, `over_budget`, `over_one_third`, and the installments due that month (`installment_no`, `installments_total`, `is_last`).
  - It uses the same counted set and the same `month_totals` as the L65 preview and the plan. (DM-01 to DM-07)
- **`GET /installments/suggested-monthly?item_price=&months=`** (`app/installments/suggest.py`): price / months, rounded UP to 0.01, as a pure function plus the endpoint. A suggestion that POST could not record is a 422. (SM-01 to SM-03)
- **`saving_if_recorded` on `POST /installments/preview`:**
  - `savings.service` is split so that recording and the preview share one path: `active_rule` (kind, auto-save, consent, rule) and `_saving` (L63 plus the 500.00 safety net).
  - `would_save` is the read-only side: no lock and no write.
  - A request id already recorded previews what POST would report (`installments.service.reported_saving`).
  - `RecordedOut.warnings` keeps its old shape. (PV-01 to PV-04)
- **`GET /buffer/shortfalls`:**
  - `assistant.plan.shortfalls` spends the buffer on each month over budget, in date order.
  - `buffer_plan` is extracted, so the totals are exactly `GET /assistant/plan`'s `buffer_plan`. (BS-01 to BS-04)
- **`GET /notifications`:** newest first by `(created_at, id)`, at most 100 shown, and `count` = all of the user's alerts. There is no read state. (NT-08 to NT-10)
- **Query strings:** `api_body.query_params` and `QueryInt` give query params the same strictness as JSON bodies:
  - unknown or repeated keys are a 422;
  - only plain ASCII digits count as numbers;
  - the 422 carries `type` and `loc` only.
- **Copy:** `SHORTFALL_BODY_NO_BUFFER` now ends with "ลองดูภาระผ่อนรายเดือนว่าจะกลับมาอยู่ในงบเมื่อไร" (your answer). The payoff assistant screen is gone. PD-01 and the copy test follow it.
