- **`GET /debts/months[?count=N]`** (`app/debts/months.py`):

The buffer is spent on the remaining gaps in date order. (BS-05, BS-07)
  - The month boundary is checked twice: the query reads `for_month >= this month`, and the plan counts a month only inside an over-budget span. (BS-06)
