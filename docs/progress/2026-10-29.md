words from numbers our code already computed, behind a pure grounding check. Any

### Risks (money, idempotency, SQL, migrations, security)
- Money: the AI never computes; every number in its text must match an input value (Decimal compare, no float). The fallback formats Decimals only.
- Idempotency: none written. The endpoint writes nothing; the cache is in memory, per user, keyed by a hash of the facts, the prompt version and the model.
- SQL: reads through the existing services only; no new query.
- Migrations: none, so the schema snapshot is unchanged.
- Security: the key is read from env only, passed to the SDK, never logged or printed; tests never touch the network (fake writer, and a guard that fails any test that builds the real client); no user free text reaches the model (no prompt-injection surface); the read transaction ends before the model call.

### Done
- **`GET /assistant/summary`** (`app/assistant/router.py`, `summary.py`): `{text, source, reason}`. The model gets only numbers, months and flags the plan already computed (`model_input`), never item names, app names or anything the user typed (AI-21, AI-22). It writes nothing (AI-22), and returns 401 without a user and 409 `SETTINGS_REQUIRED` without settings.
- **The model** (`app/ai/provider.py`): the official `anthropic` SDK, pinned at 1.14.0. One request, `max_retries=0`, an 8 s timeout, the key unwrapped from `SecretStr` only into the SDK. Errors carry only the exception type, and the key is never logged or printed (AI-15, AI-24).
- **The grounding check** (`app/ai/grounding.py`, pure). It refuses:
  - a number not in the input, in any displayed format (commas, decimals, Thai digits), and numbers in Thai words (AI-11, AI-12, AI-19);
  - a month not in the input (abbreviated, full, short, without its last dot), and a count that is not written "N เดือน", or a year without ปี or พ.ศ. before it (AI-12);
  - dashes (AI-13);
  - banned wording: prepaying, payoff order, more debt, investing, approval, "กำหนด", brand names (AI-14);
  - budget claims the facts do not support, and a wrong amount after "เกินงบ" or "ลดลง" (AI-30).
- **The fallback**: a fixed Thai template from the same facts, at most 4 lines. It passes the check for any facts (AI-20, a Hypothesis property). It is used for no key (AI-15), a timeout (AI-16), any API error (AI-17) and a failed check (AI-11 to AI-14), with no retries.
- **The cache**: per user, keyed by a hash of the facts, the prompt version and the model. Read and written under the user's lock (AI-18, AI-26). A timeout or an error is cached until the numbers change; `no_key` is not cached.
- **The prompt**: `app/ai/prompts/summary_v1.md`, versioned, with its example lines checked as one story (AI-26).
- **The test guard**: an autouse fixture fails any test that builds the real Anthropic client (AI-23).
- **`python -m demo.kidnee ai-check`**: one call per persona on `lumen_kidnee`. It prints source, reason and text, and on a refusal the failed check and the refused text. It prints whether the key is set, never its value (AI-25). Not run.
- **Frontend**: the card calls `GET /assistant/summary` in both modes.
  - The heading is "ผู้ช่วย KidNee สรุปให้ฟัง", with no "ตัวอย่าง" tag. Text shows the same way for `ai` and `fallback` (AI-27).
  - "กำลังสรุป..." while loading (AI-28).
  - A failed request shows the plan's own words (`planSummary`), never an error or an empty card. The mock answers the GET as the backend does without a key (AI-29).

### Open questions
1. **Proposed L74 (review round 1 F6, round 2 F3).** "Home's AI summary is in scope. Claude Haiku words the numbers the plan computed, behind the grounding check and the fallback. 2. `LLM_PROVIDER=anthropic` is required (round 2 F5). Default: an unset provider gives `no_key`. **For the morning check, set `LLM_PROVIDER=anthropic` and `LLM_API_KEY` in `backend/.env`.**
3. Caching a failure. Default: `timeout`, `api_error` and `grounding_failed` are cached until the numbers change, so a reload never waits 8 s again; `no_key` is not cached. A restart clears the cache. It is in memory: one entry per user, not shared across processes.
4. The 8 s timeout is the SDK's per-phase httpx timeout, not a wall clock. Default: kept, with no retries.
5. A refusal, a `max_tokens` cut-off or an empty answer. Default: `api_error`.
6. Facts beyond your list, all computed by code: the month count, the last month over, each month over's total, the buffer's covered, still-short and all-prepared flags. Income is sent, as your list says, so it reaches a third-party model. `monthly_reduction` is sent only when eligible and > 0.

8. A failed request on the frontend. Default: the plan's own words (`planSummary`), worded by the frontend, not the backend's template.
