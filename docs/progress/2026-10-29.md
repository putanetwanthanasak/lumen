### Risks (money, idempotency, SQL, migrations, security)
- Money: the AI never computes; every number in its text must match an input value (Decimal compare, no float). The fallback formats Decimals only.
- Idempotency: none written. The endpoint writes nothing; the cache is in memory, per user, keyed by a hash of the facts, the prompt version and the model.
- SQL: reads through the existing services only; no new query.
- Migrations: none, so the schema snapshot is unchanged.
- Security: the key is read from env only, passed to the SDK, never logged or printed; tests never touch the network (fake writer, and a guard that fails any test that builds the real client); no user free text reaches the model (no prompt-injection surface); the read transaction ends before the model call.
