### Bugs found
- **UI-67 could not catch a missing time zone on this machine** (B-UI-257).
  - Root cause: the machine runs at +07, so a formatter with no `timeZone` prints Bangkok time anyway. The test proved the zone only where the machine or CI happened to be elsewhere.
  - Fix: `UI_67_the_time_is_bangkok_time_whatever_the_machines_time_zone` runs `thaiTime` in a child Node process at `TZ=UTC` and at `TZ=America/New_York`. It also checks that the child really is off Bangkok time.
  - Proving test: with the zone removed it fails (07:05, expected 14:05). Fixed in ed1e99e.
